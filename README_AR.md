# نظام شركة السلطان التجاري — نسخة أولية قابلة للنشر

هذا مشروع ويب فعلي مبني على Next.js وSupabase. يتضمن كتالوجاً عاماً، تسجيل/دخول، طلب اعتماد تجار، لوحة مالك، وجدول أسعار منفصلاً محمياً بسياسات قاعدة البيانات.

## ما الذي يعمل بعد الإعداد؟
- الزوار يرون أسماء المنتجات وصورها ووصفها، ولا يمكنهم قراءة جدول الأسعار.
- كل تسجيل جديد يُنشأ كتاجر بحالة `pending` تلقائياً؛ لا يستطيع التاجر اعتماد نفسه.
- المالك يستطيع اعتماد/رفض التجار وإضافة المنتجات وتحديد الأسعار.
- الأسعار موجودة في جدول `product_prices` منفصل، وRLS يمنع قراءتها من الزوار والحسابات غير المعتمدة.
- صفحة تفاصيل المنتج تتيح بدء استفسار عبر واتساب.

## 1) إنشاء قاعدة البيانات
1. افتح https://supabase.com وأنشئ مشروعاً جديداً.
2. من لوحة المشروع افتح **SQL Editor**.
3. افتح الملف `supabase/schema.sql` وانسخ كامل محتواه إلى محرر SQL ثم اضغط **Run**.
4. من **Project Settings → API** انسخ Project URL و`anon`/publishable key.

## 2) تجهيز حساب المالك بأمان
1. شغّل الموقع محلياً كما في الخطوة التالية، ثم أنشئ حساباً من صفحة **طلب اعتماد تاجر** باستخدام بريدك أنت.
2. إذا كان تأكيد البريد مفعلاً، أكّد البريد الإلكتروني.
3. من Supabase افتح **SQL Editor** وشغّل الاستعلام التالي بعد استبدال البريد ببريدك الحقيقي:

```sql
update public.profiles
set role = 'owner', status = 'approved'
where id = (select id from auth.users where email = 'YOUR_LOGIN_EMAIL');
```

4. تحقّق من أن الاستعلام عدّل صفاً واحداً. بعدها سجّل الدخول من `/login` وستفتح لك لوحة `/admin`.
5. **لا تعطِ أحداً صلاحية Owner ولا تشارك كلمة مرور حسابك.** لا تضع `service_role` key في واجهة الموقع أو في `.env.local` الخاص بالواجهة.

## 3) تشغيل المشروع
تحتاج إلى Node.js 18.17 أو أحدث.

```bash
cp .env.example .env.local
```

عدّل `.env.local` وضع القيم الحقيقية:

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
NEXT_PUBLIC_WHATSAPP_NUMBER=963995578890
```

ثم في مجلد المشروع:

```bash
npm install
npm run dev
```

افتح http://localhost:3000 . على Windows يمكن إنشاء `.env.local` يدوياً بدلاً من أمر `cp`.

## 4) النشر على الإنترنت
يمكن نشر المشروع على Vercel وربطه بمستودع GitHub، ثم إضافة متغيرات البيئة نفسها في إعدادات المشروع على Vercel. بعد النشر، أضف عنوان الموقع إلى إعدادات Authentication/URL Configuration في Supabase، واضبط Site URL وروابط إعادة التوجيه. هذا الأرشيف لا ينشر الموقع تلقائياً ولا يحتوي على حساباتك أو مفاتيحك.

## ملاحظات مهمة قبل الاستخدام التجاري
- هذه نسخة تأسيسية: صفحة الإدارة حالياً تضيف المنتجات عبر **رابط صورة**، ولا يوجد رفع صور مباشر إلى التخزين بعد.
- واجهة عرض الأسعار تعرض العملة الافتراضية SYP؛ عدّل العملة من لوحة الإدارة/الكود إذا أردت غير ذلك.
- نموذج الطلبات موجود في قاعدة البيانات مع السياسات، لكن إرسال طلب شراء كامل وتتبّع حالته من الواجهة يحتاج استكمال واجهة الطلبات.
- يوصى باختبار السياسات بحساب زائر، وتاجر قيد المراجعة، وتاجر معتمد، والمالك قبل إدخال الأسعار الحقيقية.
- لا تُدخل بيانات سرية في بيانات المنتج العامة. لا يوجد أي سعر في جدول `products`؛ هذا مقصود لتجنب تسريبه.
